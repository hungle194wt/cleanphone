# CleanPhone web demo

A browser version of CleanPhone. Pick photos and videos, or a folder. The page compares them in the tab and does not upload them.

A browser cannot delete files on your computer. Remove from review only drops items from the list. Download the removal list and delete those files yourself.

## Run locally

```bash
npm install
npm test
npm run dev
```

## Deploy

In Vercel, set the project **Root Directory** to `web`. Framework preset: Next.js. No environment variables. See the repository README for the full steps.
